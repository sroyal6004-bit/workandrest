# 원장님 근무·휴식 공유 앱

원장님이 **언제 일을 시작했는지, 언제 쉬어야 하는지**를 직원들 기기에 실시간으로 보여주는 앱입니다.
예: 9시 30분에 근무 시작 → 90분 뒤인 11시에 "휴식 시간이에요!" 표시 → 10분 스트레칭 → "다시 일하기".

- 데스크탑(Windows/Mac 크롬·엣지)과 안드로이드 태블릿(크롬)에서 동작하는 PWA(홈 화면 설치 가능)
- 원장님 기기: **근무 시작 / 쉬기 시작 / 다시 일하기 / 퇴근** 버튼
- 직원 기기: 보기 전용으로 두면 실수로 누를 일 없음 (설정 → 조작 버튼 표시 끄기)
- 연속 근무 시간, 다음 휴식까지 남은 시간, 총 근무·휴식 횟수, 오늘 기록(시간 수정 가능)
- 휴식 시간이 되면 카드가 주황색으로 깜빡이고, 알림·알림음(선택) 발송. 미리 알림(기본 5분 전)도 가능
- 오프라인에서도 동작, 새 버전 자동 반영

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (화면·로직) |
| `manifest.json`, `sw.js`, `icon-*.png` | PWA 설치·오프라인용 |
| `firestore.rules` | Firebase 보안 규칙 |

## 1. 올리기 (GitHub Pages)

1. 이 저장소 → **Settings → Pages → Branch: main / (root)** → Save
2. 잠시 후 `https://<계정>.github.io/workandrest/` 주소로 접속
3. 크롬 주소창 오른쪽 **설치** 아이콘(또는 앱 안의 "홈 화면에 설치" 버튼)으로 설치

## 2. 기기끼리 연결하기 (Firebase, 한 번만 설정)

동기화는 Google Firebase의 Firestore를 사용합니다. 무료 범위로 충분합니다.

1. https://console.firebase.google.com → **프로젝트 추가** → 이름 입력(예: workandrest) → Google 애널리틱스는 꺼도 됨 → 만들기
2. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기** → 위치는 `asia-northeast3 (Seoul)` → **프로덕션 모드**로 시작
3. Firestore 화면 상단 **규칙** 탭 → 내용을 모두 지우고 이 저장소의 `firestore.rules` 내용을 붙여넣기 → **게시**
4. 프로젝트 개요 옆 **⚙ → 프로젝트 설정 → 일반** 하단 **내 앱 → 웹(</>)** 추가 → 앱 이름 입력 → 등록
5. 화면에 나오는 `const firebaseConfig = { apiKey: "...", ... }` 부분을 복사

앱에서:

6. **⚙ 설정 → Firebase 설정** 칸에 5번에서 복사한 내용을 그대로 붙여넣기 (중괄호 `{ ... }` 부분만 있어도 됨)
7. **연결 코드**에서 **새로 만들기** → 코드가 생성됨 (10자 이상이면 직접 정해도 됨)
8. **동기화 상태 점검** → 읽기/쓰기 모두 ✅ 인지 확인 → **저장**
9. 직원 기기에서도 같은 주소로 앱을 열고 **같은 Firebase 설정 + 같은 연결 코드**를 넣으면 끝

> 연결 코드는 비밀번호 역할입니다. 직원에게만 알려주세요.
> 매 기기마다 붙여넣기가 번거로우면 `index.html` 상단의 `FIREBASE_CONFIG = null` 을
> `FIREBASE_CONFIG = { apiKey: "...", ... }` 로 바꿔 두면 연결 코드만 넣으면 됩니다.

## 3. CRM 옆에 띄우기

| 상황 | 방법 |
|---|---|
| **데스크탑(크롬·엣지)** | 앱의 **"떠 있는 창"** 버튼 → 다른 프로그램 위에도 항상 보이는 작은 창이 열림. 버튼도 그 안에서 바로 누를 수 있음 |
| 데스크탑(그 외) | **"옆에 작은 창"** 버튼 → 화면 오른쪽에 작은 창이 열림. CRM 창을 왼쪽에, 이 창을 오른쪽에 두기(Windows: 창 끌어서 스냅) |
| **안드로이드 태블릿** | 앱을 홈 화면에 설치 → CRM 앱 실행 중 최근 앱 버튼 → **화면 분할** → 오른쪽에 이 앱을 두기. 좁은 폭에 맞춰 자동으로 축소 표시됨 |
| 안내판처럼 항상 켜둘 때 | 설정 → **화면 항상 켜기** 켜기 |

주소 뒤에 `?mini=1` 을 붙이면(예: `.../workandrest/?mini=1`) 기록 없이 시간과 버튼만 나오는 미니 화면으로 열립니다.

## 4. 사용법

1. 원장님 기기에서 **▶ 근무 시작**
2. 90분(설정 가능) 뒤 모든 기기에 **"휴식 시간이에요!"** 표시 + 알림
3. **🧘 쉬기 시작** → 10분(설정 가능) 카운트 → **💪 다시 일하기**
4. 하루가 끝나면 **퇴근**
5. 버튼 누르는 걸 잊었다면 오늘 기록의 시간을 눌러 수정
